== Kitin sağlık denetimindeki adres (localhost) bugün de başarısız ==
$ docker exec bsm461-s3 wget -q -O /dev/null http://localhost:9333/cluster/status; echo $?

çıkış kodu 1

$ docker exec bsm461-s3 wget -q -O /dev/null http://127.0.0.1:9333/cluster/status; echo $?

127.0.0.1	localhost
